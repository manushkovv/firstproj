#вопрос1 - делегат
делегат - это паттерн, где один объект передаёт задачу другому через протокол. протокол не всегда обязателен (бывают костыльные реализации). главная задача - это передача обработки состояния (задачи) другому, но если делегат не назначен, он и сам может выполнять обработку
в моем проекте AppDelegate реализует протокол UIApplicationDelegate и система делегирует управление циклом приложения.
